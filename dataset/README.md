# dataset

esta pasta guarda algumas imagens simples usadas no projeto.

a ideia aqui não é montar uma base grande. o objetivo é ter poucas imagens para testar o fluxo de recomendação visual sem deixar o notebook pesado.

categorias usadas:

- relógios
- tênis
- camisetas

as imagens são pequenas e servem apenas como exemplo para extrair embeddings com uma rede pré-treinada.
